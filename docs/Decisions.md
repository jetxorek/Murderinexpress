# Architectural Decision Records

## ADR-019: Процедурный звук через Web Audio API

**Дата:** 2026-03-16  
**Статус:** Принято

### Контекст

Для MVP игры «Убийство в Дальневосточном экспрессе» необходимо атмосферное звуковое сопровождение. Аудиофайлы (музыка, эффекты) отсутствуют и не будут добавлены в MVP из-за ограничений по размеру бандла и отсутствию лицензированного контента.

### Решение

Использовать **процедурный звук** через нативный Web Audio API вместо аудиофайлов. Звуки синтезируются «на лету» из осцилляторов, шума и фильтров.

### Обоснование

1. **Нулевой размер ассетов** — нет необходимости загружать аудиофайлы
2. **Мгновенная загрузка** — звук доступен сразу после инициализации
3. **Tree-shakable** — импортируются только используемые пресеты
4. **Кросс-платформенность** — Web Audio API поддерживается во всех современных браузерах
5. **Гибкость** — легко менять параметры звука (частоты, громкости, тайминги) без пересборки ассетов
6. **Соответствие духу проекта** — процедурный звук добавляет уникальность и атмосферность

### Альтернативы

- **Аудиофайлы (MP3/OGG)** — требуют лицензирования, увеличивают размер бандла
- **MIDI-синтезаторы** — избыточны для простых ambient-звуков
- **Сторонние библиотеки (Tone.js)** — добавляют зависимость, избыточны для MVP

### Архитектура

```
src/services/audio/
├── types.ts          # Типы AudioPresetId, AudioApi
├── context.ts        # Singleton AudioContext, master GainNode
├── noise.ts          # Генератор brown-noise AudioBuffer
├── presets.ts        # Реестр пресетов (9 процедурных звуков)
├── player.ts         # Управление пресетами, crossfade
├── sceneMap.ts       # Маппинг экранов/сцен на пресеты
├── api.ts            # Публичный API (singleton audio)
└── index.ts          # Реэкспорт
```

### Пресеты

1. `silence` — тишина
2. `menu_theme` — эмбиент главного меню
3. `summary_theme` — спокойный тон для сводки главы
4. `train_ambient` — гул поезда с ритмом колёс
5. `night_corridor` — шум метели за окном
6. `tension` — напряжённый минорный дрон
7. `death_sting` — короткий аккорд для момента смерти
8. `accusation_theme` — напряжённый тон для обвинения
9. `finale_theme` — мажорный аккорд для морального выбора

### API

```typescript
export const audio: AudioApi = {
  init: () => void;                     // создать/resume AudioContext
  isInitialized: () => boolean;
  playPreset: (id: AudioPresetId) => void;  // crossfade с текущим
  stop: () => void;                     // fade out + suspend
  setVolume: (v: number) => void;       // 0..1, сохраняется в localStorage
  getVolume: () => number;
  setMuted: (b: boolean) => void;
  isMuted: () => boolean;
};
```

### Интеграция

Аудио инициализируется по user gesture (клик по кнопке «Новая игра» или «Продолжить»). При смене экрана/сцены вызывается `audio.playPreset(getPresetForScreen(screen, sceneId))`.

### Последствия

- **Положительные:** нулевой размер ассетов, мгновенная загрузка, уникальность
- **Отрицательные:** звук менее богат, чем записанная музыка; требует больше CPU
- **Риски:** Web Audio API может быть заблокирован в некоторых браузерах до user gesture

### Миграция

Не требуется. Аудио-система изолирована в `src/services/audio/` и не влияет на другие модули.
